# Monthly Full Enrollment Data File

Versions 5.0-19.0 are currently supported. Some of these are autogenerated and thus missing from the repository.

(Despite the name, FEFD is not a typo. This is how it appears in the documentation. See *Full Enrollment File*, page 3-23 in PCUG v19.0.)

## Layout

The file has only one type of record, no header or trailer.

```mermaid
stateDiagram-v2
    [*]    --> record
    record --> record
    record --> [*]
```
