# MARx Transaction Records

There are sixteen different data record types.

GFM test

Required for all Plan types except HCPP, COST 1 without drug, COST 2
without drug, CCIP/FFS demo, MDHO demo, MSHO demo, and PACE National Plans.

* MAs have A, D, I, L[^retronote], M, N, O, S, T, U, V, W, X.
* MAPDs have A, D, E, I, L†, M, N, O, S, T, U, V, W, X, Z.
* PDPs have A, E, L†, S, U, V, W, X, Z.

[^retronote]: † For RPC Retroactive transactions only effective 1/1/2025. Plan
disenrollment transactions after 1/1/2025 will reject.
