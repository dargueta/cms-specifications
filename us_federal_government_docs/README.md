# Contents

## Plan Communications User Guide (PCUG)

These are descriptions of the file formats used to convey information from CMS to Medicare Advantage plans. The latest version is available on CMS's site [here](https://www.cms.gov/data-research/cms-information-technology/access-cms-data-application/mapd-plan-communication-user-guide). There's no easy way to find historical versions, which can be a real problem: Sometimes CMS takes a while to update the format of the files they're actually sending to match the documentation.
